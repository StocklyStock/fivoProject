# 🧠 FIVO - AI 기반 주식 분석 플랫폼

**FIVO**는 AI를 활용하여 **주식 뉴스 감성 분석**, **실시간 테마 시각화**, **종목 요약 추천**, **투자자 알림 기능**을 제공하는 차세대 주식 분석 웹 플랫폼입니다.

---

## 🚀 주요 기능

### 1. 📊 실시간 테마 트리맵 시각화

- 실시간 주가 변화에 따라 테마별 종목을 트리맵 형태로 시각화
- WebSocket 기반 FastAPI 서버와 연동
- D3.js 기반 인터랙티브 UI 구현

### 2. 📰 뉴스 감성 분석

- 수천 개 종목별 뉴스 데이터를 수집 및 정제
- BERT 기반 모델로 감성 라벨링 진행 (긍정/부정)
- 향후 주가 상승/하락 예측 보조 자료 제공

### 3. 📈 종목 요약 및 리스크 분석

- 종목별 이슈 요약, 투자 포인트, 감성 흐름 시각화
- 관련 뉴스 자동 연결

### 4. 🔔 실시간 알림 기능 (추후 확장)

- 특정 조건 만족 시 사용자에게 알림 발송 예정
- 감성 악화, 주가 급등/급락 등 기준 설정 가능

## 🎯 프로젝트 목표 – Fivo

> “데이터로 시장을 읽고, 예측하고, 행동하게 하라.”

### 🧠 1. AI 기반 주식 뉴스 분석 & 감성 예측

- 대규모 증권 뉴스 데이터를 수집·정제하여
- 최신 딥러닝 모델(BERT 등)을 활용한 감성 분석을 수행하고
- 주가 흐름과의 관계를 정량적으로 분석

### 📊 2. 실시간 테마 주식 시각화

- 투자자들이 당일 시장의 핵심 흐름을 트리맵 차트로 직관적으로 확인할 수 있도록
- 실시간 테마 데이터 기반으로 테마별 종목·변동률을 애니메이션 형태로 시각화

### 🤖 3. 개인화된 AI 추천 시스템

- 감성 기반 뉴스 분석 + 주가 라벨링 데이터를 기반으로
- 사용자의 관심 종목 및 테마 흐름에 따라 맞춤형 종목/테마 추천

### 💬 4. 카카오톡 스타일 챗봇 UI

- "엔비디아 오늘 사도 돼?" 같은 자연어 질문에
- 관련 뉴스를 분석해 요약 + 감성 결과를 함께 제공하는
- 대화형 챗봇 시스템을 웹 우측 하단에 배치

### 🔄 5. 전반적인 자동화 & 실시간성 확보

- AWS 기반 인프라에 WebSocket, Docker, CI/CD 파이프라인까지 구성
- 개발 → 배포 → 운영까지 끊김 없이 자동화되는 구조 설계
